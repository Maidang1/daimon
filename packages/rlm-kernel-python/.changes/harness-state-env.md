- Changed: the kernel spawn now exports `RLM_HARNESS_STATE_DIR` and `RLM_GLOBAL_HARNESS_STATE_DIR`, resolved from `DSH_HOME` through the same path helpers `@deepseek-ai/dsh-rlm-harness-local` uses. The runtime's model-facing `rlm.harness` state and the host-side `ctx.rlmHarness` provider read and write one JSON store per scope (`<dshHome>/rlm/harness/...`) instead of two divergent stores; the Python local scope no longer degrades to a volatile in-memory fallback.
